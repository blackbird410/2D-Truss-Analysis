# Runtime Data Directory

This directory contains runtime data generated by the application:

- **Output files:** Analysis results, exported calculations
- **Temporary data:** Cache files, intermediate results
- **User projects:** Saved truss models

## Git Behavior

This directory is git-ignored except for:

- `.gitkeep` (to preserve directory structure)
- This README

## Usage

Applications write output to this directory when:

1. User saves analysis results
2. Export operations generate files
3. Configuration cache is stored

## Cleanup

Data in this directory is safe to delete. The application will recreate it as needed.
