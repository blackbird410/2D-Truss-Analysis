Detailed Description

Read-only table model that exposes member data from ITrussView.

Columns (12 total): 0 ID 1 Start Node 2 End Node 3 Material 4 E [GPa] 5 A [cm²] 6 Length [m] 7 Angle [°] 8 Force [kN]* 9 Stress [MPa]* 10 Util. Ratio* 11 State*

Columns 8–11 display "—" until setHasResults(true) is called.

Roles: Qt::DisplayRole — formatted string Qt::ForegroundRole — colour-coded text on column 10 (utilisation ratio) 0.0 → green (#34A853), 0.75 → amber (#FFC107), ≥1.0 → red (#EA4335) Qt::ToolTipRole — state detail on column 11 Qt::TextAlignmentRole — right-align numeric columns

Thread safety: all methods must be called from the GUI thread.
