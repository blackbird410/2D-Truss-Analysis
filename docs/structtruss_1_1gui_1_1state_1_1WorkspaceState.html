Detailed Description

Complete, immutable description of GUI workspace state at an instant.

WorkspaceState is a plain value type: it is cheap to copy, equality- comparable, and carries no pointers or reference semantics. MainWindowController owns the canonical copy and emits stateChanged(WorkspaceState) whenever it transitions. Panels replace their local copy on every emission.

Handle values of 0 are treated as "invalid / not set".
