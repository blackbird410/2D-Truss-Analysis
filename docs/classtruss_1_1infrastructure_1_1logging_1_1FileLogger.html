Detailed Description

Logger that outputs to a file.

Features:

  • Thread-safe file writing
  • Automatic file creation
  • Append mode (preserves existing logs)
  • Timestamps on messages
  • Automatic flushing for critical errors

Note: Lifecycle messages (initialization/shutdown) are written at INFO level and bypass the configured minimum level filter to ensure proper logger state tracking in log files.

Thread Safety: Fully thread-safe via mutex
