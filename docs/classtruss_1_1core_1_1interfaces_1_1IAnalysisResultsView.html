Detailed Description

Read-only view interface for AnalysisResults.

This interface allows Infrastructure layer (exporters) to access analysis results without depending on the concrete AnalysisResults struct.

Benefits:

  • Infrastructure depends on abstraction, not concrete type (DIP)
  • Domain controls what data is exposed to Infrastructure
  • Changes to AnalysisResults don't force Infrastructure recompilation
