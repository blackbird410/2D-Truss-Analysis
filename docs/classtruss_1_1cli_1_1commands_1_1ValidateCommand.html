Detailed Description

Command for validating truss structures.

Usage: TrussAnalysisCLI validate –file <path> [–verbose]

Options: –file, -f Input file path (required) –verbose, -v Enable verbose output with detailed validation results

Validation Categories:

  • Structural validity (nodes, members, connectivity)
  • Support conditions (adequate constraints)
  • Loading conditions
  • Material properties
  • Section properties
  • Geometry (member lengths, angles)
  • Stability
  • Numerical conditioning

Example: TrussAnalysisCLI validate -f bridge.json -v
