Detailed Description

List model that exposes validation issues from a ValidationResult.

Each row represents one ValidationIssue.

Roles: Qt::DisplayRole — "[CATEGORY] message" Qt::DecorationRole — 12×12 colour square per severity: Info=steel-blue, Warning=amber, Error=red, Fatal=dark-red Qt::ToolTipRole — technicalDetail string (if non-empty) Qt::UserRole + 1 — QVariant(quint32) first affected NodeId, or 0 Qt::UserRole + 2 — QVariant(quint32) first affected MemberId, or 0

These UserRole values let controllers navigate the canvas to the issue location.

Thread safety: all methods must be called from the GUI thread.
