Detailed Description

Workspace state value types for GUI state management.

This header is intentionally Qt-free. It defines pure value types that describe the complete state of the GUI workspace at any point in time.

Owned by MainWindowController. All panels observe state transitions via the stateChanged(WorkspaceState) signal; no panel holds a reference to another panel's state.

enum class truss::gui::state::WorkspacePhase : std::uint8_t

Represents the current phase of the workspace workflow.

Phases drive which controls are enabled/disabled. Advancing through the workflow transitions the phase; panels subscribe to phase changes and update their enabled state accordingly.

State machine transitions:
