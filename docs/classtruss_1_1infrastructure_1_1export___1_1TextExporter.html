Detailed Description

Plain text format exporter.

Exports analysis results to human-readable plain text format. Produces formatted output with headers, separators, and aligned columns.

CRITICAL: This implementation follows the corrected 8-section export contract. ALL 8 sections MUST be included to maintain semantic equivalence with CSV, JSON, XML, HTML, and LaTeX exporters. Text is just another presentation layer.

8-Section Contract (MANDATORY):

  1. Project metadata
  2. Geometry (nodes + members)
  3. Material properties (placeholder until domain model implements)
  4. Applied loads (placeholder until domain model implements)
  5. Displacements
  6. Member forces
  7. Reactions (MANDATORY for equilibrium verification)
  8. Analysis metadata

Text Output Features:

  • Clear section headers with separator lines
  • Column-aligned tabular data
  • Box-drawing characters for visual structure
  • Readable without special tools or parsing
  • Fixed-width formatting for easy viewing in terminals
