Detailed Description

Command for analyzing truss structures from files.

Usage: TrussAnalysisCLI analyze –file <path> [–output <path>] [–format <format>]

Options: –file, -f Input file path (required) –output, -o Output file path (optional, for results export) –format Export format (JSON|XML|CSV|TSV|TXT|YAML|MARKDOWN) –verbose, -v Enable verbose output

Example: TrussAnalysisCLI analyze -f bridge.json -o results.csv –format CSV
