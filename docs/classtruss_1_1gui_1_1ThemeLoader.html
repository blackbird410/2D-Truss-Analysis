Detailed Description

Static helper class that loads QSS stylesheets from Qt resource paths and applies them to the running QApplication.

Theme selections are persisted via QSettings so the user's preference survives application restarts.

QSettings scope: Organisation: "TrussAnalysis" Application: "GUI" Key: "theme/path" (value: resource path string)
