Detailed Description

Read-only table model that exposes node data from ITrussView.

Columns (10 total): 0 ID 1 X [m] 2 Y [m] 3 Support 4 Fx [kN] 5 Fy [kN] 6 dx [mm] * 7 dy [mm] * 8 Rx [kN] * 9 Ry [kN] *

Columns 6–9 display "—" until setHasResults(true) is called.

Roles: Qt::DisplayRole — formatted string Qt::BackgroundRole — amber tint for nodes with non-zero applied load Qt::ToolTipRole — support type description for column 3 Qt::TextAlignmentRole — right-align numeric columns

Thread safety: all methods must be called from the GUI thread.
