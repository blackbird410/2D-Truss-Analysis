Detailed Description

Abstract interface for results exporters.

Defines the contract for all concrete exporter implementations. Each exporter is responsible for a single format (CSV, JSON, XML, etc.).

Design Pattern: Strategy

  • Context: ExporterFactory
  • Strategy: IResultsExporter (this interface)
  • Concrete Strategies: CSVExporter, JSONExporter, etc.

Architecture: Depends on abstractions (ITrussView, IAnalysisResultsView), not concrete Domain types (Truss, AnalysisResults). This enforces DIP.
