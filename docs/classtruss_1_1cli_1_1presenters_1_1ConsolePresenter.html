Detailed Description

Handles all formatted console output for CLI.

Consumes view interfaces (ITrussView, IAnalysisResultsView) to format and display data without direct Domain access.

Architecture:

  • Depends on IApplicationOutput (Application layer abstraction)
  • Formats data into strings (presentation concern)
  • Delegates output routing to abstraction (no direct I/O)
