Detailed Description

Translates canvas interaction signals into ITrussAnalysisFacade calls.

CanvasController is constructed with a facade reference and a default truss handle. When the user drops a node or draws a member on the canvas the corresponding signal is forwarded here; the controller calls the facade and emits trussModified(handle) on success or operationFailed(message) on failure. The active handle is updated via onTrussHandleUpdated.

The default material/section for new members starts as Steel/100 cm² and is updated at runtime by wiring InspectorPanel::defaultMaterialChanged to onDefaultMaterialChanged. This replaces the old compile-time constants.
