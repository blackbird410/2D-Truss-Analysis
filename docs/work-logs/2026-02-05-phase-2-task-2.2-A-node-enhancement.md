#### 2. Node.cpp Implementation

**File:** `src/core/Node.cpp`

**Method Implementations:**

```cpp
bool Node::isConstrained() const noexcept {
    return m_supportType != SupportType::Free;
}

int Node::getDegreesOfFreedom() const noexcept {
    return getDofCount();  // Delegates to existing method
}

std::vector<Index> Node::getGlobalDOFs() const {
    std::vector<Index> dofs;
    dofs.reserve(2);

    // Add X DOF if not constrained in X
    if (!isConstrainedX()) {
        dofs.push_back(m_dofX);
    }

    // Add Y DOF if not constrained in Y
    if (!isConstrainedY()) {
        dofs.push_back(m_dofY);
    }

    return dofs;
}
```

**Bug Fix Discovered:**

During testing, discovered incorrect constraint logic for RollerY support:

```cpp
// BEFORE (incorrect):
bool Node::isConstrainedX() const noexcept {
    return m_supportType == SupportType::PinnedX ||
           m_supportType == SupportType::Pinned;
}

// AFTER (correct):
bool Node::isConstrainedX() const noexcept {
    return m_supportType == SupportType::PinnedX ||
           m_supportType == SupportType::Pinned ||
           m_supportType == SupportType::RollerY;  // FIX: RollerY constrains X
}
```

**Support Type Logic Table:**

| Support Type | Constrained X | Constrained Y | DOFs |
| ------------ | ------------- | ------------- | ---- |
| Free         | ❌            | ❌            | 2    |
| PinnedX      | ✅            | ❌            | 1    |
| PinnedY      | ❌            | ✅            | 1    |
| Pinned       | ✅            | ✅            | 0    |
| RollerX      | ❌            | ✅            | 1    |
| RollerY      | ✅            | ❌            | 1    |

**Constraint Semantics:**

- **RollerX**: Roller allowing movement in X direction → Constrains Y
- **RollerY**: Roller allowing movement in Y direction → Constrains X
