Detailed Description

Application service for truss model operations.

This service acts as a facade between the Interface layer and the Domain/Infrastructure layers. It coordinates operations across multiple subsystems while keeping the Interface layer decoupled from implementation details.

Thread Safety: Not thread-safe (intended for single-threaded GUI/CLI applications)

Usage Example:

TrussApplicationService service;
auto result = service.createTruss("MyBridge");
if (result) {
TrussHandle handle = result.value;
const auto& view = service.getTrussView(handle);
// Use view to read truss data...
}
