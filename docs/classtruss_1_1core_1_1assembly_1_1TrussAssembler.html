Detailed Description

Assembles Domain objects from DTOs.

This utility class provides static methods to convert DTOs (created by Infrastructure layer during file reading) into Domain objects. This separation ensures Infrastructure depends only on data structures, not concrete Domain implementations.

Design Pattern: Factory/Builder pattern for Domain object construction SOLID: Enforces Dependency Inversion Principle (DIP)

Usage:

TrussDTO dto = reader->read("truss.json");
auto truss = TrussAssembler::assembleTruss(dto);
